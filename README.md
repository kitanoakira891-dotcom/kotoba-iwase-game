# ことばポイント

友人同士で「指定した言葉を言った回数」と得点をリアルタイム共有する、静的なWebアプリです。

## 機能

- Firebase匿名認証（参加者のアカウント登録は不要）
- 全員が参加する固定の共有ルーム
- 表示名をブラウザに保存し、次回から自動参加
- Firestoreによるリアルタイム同期と同時加算に強いトランザクション
- 初期得点表17項目
- 全参加者による言葉・得点の追加、編集、削除
- 各参加者が自分で加算したカウントの取り消し
- 参加者ごとのカウント・得点ランキング
- 得点変更時の累計再計算
- 10点項目の強調、得点帯ごとの色分け、スマートフォン対応

## Firebase設定

1. Firebase Consoleでプロジェクトを作成します。
2. AuthenticationのSign-in methodで「匿名」を有効にします。
3. Firestore Databaseを作成します。
4. プロジェクト設定からWebアプリを追加します。
5. 表示された `firebaseConfig` を `firebase-config.js` に貼り付けます。
6. Firestoreの「ルール」に `firestore.rules` の内容を貼り付けて公開します。

`firebase-config.js` の値はWebブラウザに公開される識別情報であり、秘密鍵ではありません。データ保護はAuthenticationとFirestore Security Rulesで行います。サービスアカウント鍵などの秘密情報は絶対に置かないでください。

## ローカル確認

ファイルを直接開かず、このフォルダーをWebサーバーで配信します。

```bash
python -m http.server 8000
```

その後、`http://localhost:8000` を開きます。実運用前には別ブラウザーまたはプライベートウィンドウから参加し、同期・権限・同時加算を確認してください。

## 公開

GitHub PagesなどのHTTPS対応静的ホスティングに、HTML・JavaScript・CSSなどのファイルをそのまま配置できます。公開前に必ず対象Firebaseプロジェクトへ `firestore.rules` を反映してください。

## セキュリティと運用上の注意

- このFirebaseプロジェクトを利用する匿名認証済みユーザーは、共通ルームを閲覧できます。機密情報は登録しないでください。
- 言葉・得点の追加、編集、削除は全参加者が実行できます。カウントの減算は本人が加算した分だけ可能です。
- 表示名はブラウザのローカルストレージに保存されます。サイトデータを消すと再入力が必要です。
- 部屋は自動削除されません。長期運用では有効期限フィールドと定期削除処理を追加してください。
- 公開規模が大きい場合は、Firebase App Check、予算アラート、使用量監視も設定してください。
- Firebase SDKはCDNから読み込むため、初回表示にはインターネット接続が必要です。
