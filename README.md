# いや～でも～って言わせるゲーム

Firebase匿名認証とFirestoreを使うリアルタイム共有ゲームです。

## 参加方法
- 一般参加: 表示名を入れて「一般参加」
- 管理者参加: 表示名と管理者パスワードを入れて「管理者権限で参加」
- 管理者パスワードは `UNKO`
- 管理者モードでは他の参加者と、その参加者の個人スコアを削除できます。

## 重要なセキュリティ上の注意
この方式は友人間の簡易利用向けです。静的Webアプリ内のパスワードは閲覧可能であり、Firestoreルールは匿名認証済み利用者の削除を許可しています。公開URLを不特定多数へ配布しないでください。本格的な管理者認証にはFirebase AuthenticationのGoogleログインとCustom Claims等が必要です。

## 公開
1. 全ファイルをGitHub Pagesへ上書きします。
2. `firestore.rules` の内容をFirebase ConsoleのFirestore Rulesへ貼り付けて公開します。
3. 新旧キャッシュを避けるため、公開後にブラウザを再読み込みします。

### 統計表示
- 言葉別の累計回数は横棒グラフで表示します。
- 発言日時は参加者別のタイムライングラフで表示します。
- 統計の表形式表示はありません。
- タイムラインはFirestoreから取得した直近100件を使用します。

### 参加者削除時
削除した参加者のカウント、得点、タイムライン履歴は全体集計から除外されます。

### 集計修正と全リセット
- 画面の合計値と統計グラフは、現在の参加者の `memberWords` から再集計します。
- 管理者画面には「全員のスコアと統計をリセット」ボタンが表示されます。
- リセットは全 `memberWords`、全 `events` を削除し、全 `words` の `count` と `totalScore` を0にします。
- `app.js?v=20260904-2` として読み込み、GitHub Pagesの古いJavaScriptキャッシュを避けます。

### 発言タイムライン v3
横軸を時刻、縦軸を言葉ごとの累計回数、凡例を言葉とし、全プレイヤーを合算して表示します。
