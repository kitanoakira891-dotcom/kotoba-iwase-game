# 安定版ベース + 複数部屋・得点表管理

添付された安定版をベースに、以下だけを追加しています。
- ログイン後の部屋作成
- 作成済み部屋一覧と自由な出入り
- 各部屋で得点表のSAVE・LOAD・DELETE
- 同名得点表は上書き、最大5件

既存の加減算、参加者スコア、統計、管理者参加、参加者削除、全リセット、言葉編集は維持しています。

公開時は全ファイルをGitHub Pagesへ上書きし、firestore.rulesをFirebase Consoleへ反映してください。


## 発言タイムライン軸修正
横軸の日時目盛と「時刻」、縦軸の回数目盛と「累計回数」、軸線、グリッド、データ点を追加しました。その他の機能は変更していません。
